# Ninos

Barrakudes' mascot figures: blobby characters drawn with a thick black outline on white. [`STYLE.md`](STYLE.md) is the style guide, originally a prompt for generating new ones with AI.

| Folder | Contents |
|---|---|
| `figures/` | 49 ninos (`nino-<what it does>.svg`) |
| `objects/` | 9 props in the same style: skull, bottle, cookie, snack bag, sweet, pizza, drop, disco ball, star |
| `examples/` | A full illustration (`ilustracio-casa-festa.svg`), a colour-filled variant (`nino-ple-taronja.svg`) and an AI preview of many ninos together |

## Using them in the Quina

- **Family audience.** The Quina is a family event, so pick figures with that in mind:
  - Never use `nino-sexe.svg`.
  - Think twice about the drinking ones (`nino-beguda`, `nino-beguda-doble`, `nino-paracaigudes-cervesa`, `nino-helicopter-gin`).
- **Adapting the style.** The doodle style (white fill, no colour) doesn't match the game look of the player-facing screens. Adapting them (flat colour fills, a sticker border, a soft shadow) is expected. Dropping them is also fine if it doesn't work.
