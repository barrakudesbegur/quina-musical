# Brand assets

Barrakudes artwork shared by every part of the Quina musical: printed cards, projector, console and player app.

- [`ninos/`](ninos/): the Barrakudes mascot figures ("ninos") and their style guide.
- The Barrakudes logo currently lives in `card-generator/src/assets/`.

Assets here are sources. Apps should copy or process what they need (for example colour-filled game-style versions, WebP exports) into their own build, not edit these files.
